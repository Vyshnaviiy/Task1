# Tachyon AIML Intern Pre-boarding Practice

This folder contains one simple, runnable example for each pre-boarding topic.
Each topic folder has its own `README.md` with the exact commands to run.

## Folder Map

1. `01_python_fundamentals` - read JSON, filter a list of dictionaries, print results.
2. `02_git_github_basics` - small Python file plus Git/GitHub command checklist.
3. `03_html_css_js_basics` - plain HTML/CSS/JavaScript page that uses `fetch()`.
4. `04_docker_fundamentals` - Dockerfile for a simple Python script.
5. `05_fastapi_intro` - FastAPI app with GET and POST routes, Pydantic, and CORS.
6. `06_reactjs_basics` - React component that fetches from the FastAPI backend.
7. `07_react_router_v7` - three-page React Router app with a sidebar.
8. `08_tailwind_css` - Tailwind-styled page using spacing, flexbox, colors, and responsive breakpoints.
