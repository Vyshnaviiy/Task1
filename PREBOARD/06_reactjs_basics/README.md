# 06 - ReactJS Basics

## Done When Goal

Build a React component that calls the local FastAPI endpoint from topic 05 on page load, stores the result in `useState`, and renders a list.

## Run It

First start the FastAPI app from `../05_fastapi_intro` on port 8000.

Then run React:

```bash
cd PREBOARD/06_reactjs_basics
npm install
npm run dev
```

Open the Vite URL shown in the terminal.
